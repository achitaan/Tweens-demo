# Tweens hosted preview

Public compiled preview, licensed HERO excerpts and generated controls.

Open https://achitaan.github.io/Tweens-demo/

Inspect two HERO animation excerpts and a synthetic control, edit the blockouts, orbit and scrub time, then save in this browser or export JSON/GLB. Import a PNG/JPEG, build a manual blockout and record reversible fragment links in this browser. Video import and Python/CUDA reconstruction run in the local app. HERO footage is credited to Blender Foundation under CC BY 4.0; see demo/ATTRIBUTION.html for source, license and changes. Its depth-varying surfaces come from local Depth Anything V2 Small predictions. They are single-view 2.5D hypotheses with unmeasured scale and unknown hidden geometry, not validated anime reconstruction. The synthetic control is prearranged.
