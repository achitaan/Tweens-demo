# Tweens hosted preview

Public compiled preview, licensed HERO excerpts and generated controls.

Open https://achitaan.github.io/Tweens-demo/

Inspect two HERO animation excerpts and a synthetic control, edit the blockouts, orbit and scrub time, then save in this browser or export JSON/GLB. Video import and Python/CUDA reconstruction run in the local app. HERO footage is credited to Blender Foundation under CC BY 4.0; see demo/ATTRIBUTION.html for source, license and changes. Its blockouts come from the provisional geometry-only pipeline and have not been validated for animation accuracy. The synthetic control is prearranged.
