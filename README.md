# Tweens hosted preview

Public compiled preview, licensed HERO excerpts and generated controls.

Open https://achitaan.github.io/Tweens-demo/

Inspect two HERO animation excerpts and a synthetic control, edit the blockouts, orbit and scrub time, then save in this browser or export JSON/GLB. Import a PNG/JPEG, build a manual blockout and record reversible fragment links in this browser. Video import and Python/CUDA reconstruction run in the local app. HERO footage is credited to Blender Foundation under CC BY 4.0; see demo/ATTRIBUTION.html for source, license and changes. Segmented depth-shaped region meshes use source boundaries, SAM proposals and relative-depth hypotheses. Side closures, back caps, the floor and camera calibration remain inferred. These incomplete regions are not recognized or complete buildings. Source-angle estimates are conditional; image warps do not establish camera travel. The depth sheet remains a comparison alternative. Anime accuracy is unvalidated. The synthetic control is prearranged.
